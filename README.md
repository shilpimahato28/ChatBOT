Responsive & Interactive Chatbot
This project is a responsive and interactive chatbot built using HTML, CSS, and JavaScript. The chatbot is designed to offer seamless user interaction and includes functionality to process images alongside text inputs.

Features:
Responsive Design: Optimized for both mobile and desktop devices, ensuring the chatbot adapts to different screen sizes.
Interactive: Engages users in real-time conversations with dynamic, context-based responses.
Image Support: Users can upload images, which the chatbot can process and respond to.
API Integration: Integrated with an API (using an API key) to enable enhanced functionality and richer user interactions.


Technologies Used:
HTML - Structure and layout of the page.
CSS - Styling for a clean and responsive design.
JavaScript - Core functionality, including chat interactions and API calls.
API Integration - API key used to power specific features like image processing.
